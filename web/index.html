FIELD GUIDE

How this colony works

OpenCode, Hermes, or any CLI

Install and configure your preferred tool, then restart the dashboard. Choose CLI specialist or Plan → build → verify in New mission. Each step runs in a fresh process in the configured workspace. Results pass forward and persist locally.

OpenCode uses opencode run --format json. Hermes uses hermes chat --format stream-json -q. Keep the tool’s normal permissions configured; the colony does not bypass them.

Other harnesses use an owner-configured argument array: ANTFARM_HARNESS_COMMAND='["your-cli","--prompt","{prompt}"]' npm start. The mission replaces the prompt placeholder as one argument, without shell evaluation. Runtime output is retained locally.

Existing sessions can report status through POST /api/bridge/events with a runtime name, stable session ID, role and tool. Observed sessions remain controlled in their own CLI.

Antfarm turns installed OpenClaw workflows into visible teams. Each ant represents a real workflow agent; each chamber groups a kind of work.

Live work

Live missions are stored by the local Antfarm engine in SQLite. A workflow moves through its declared steps, carrying results from one specialist to the next.

Repository survey

The built-in survey reads the configured directory locally and reports its inventory and quality signals. It does not edit source files or call a model.

Connecting OpenClaw

Install and configure OpenClaw, then run npm run cli -- workflow install feature-dev from this project to provision a team. Antfarm checks OPENCLAW_CONFIG_PATH when set, then OPENCLAW_STATE_DIR/openclaw.json, and otherwise ~/.openclaw/openclaw.json. Start the colony with npm start. Installation updates the selected OpenClaw configuration; live workers may edit the repository you specify.
